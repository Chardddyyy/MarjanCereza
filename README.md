# Marjan Cereza - Portfolio

A personal portfolio website for Marjan Cereza featuring interactive cursor effects, responsive design, and PIN-protected access.

## Live Preview & Usage

To run locally:
```bash
# Using Python
python3 -m http.server 3000

# Or using Node.js / npx
npx serve .
```

Open your browser and navigate to `http://localhost:3000`.

## Files
- `index.html` - Main portfolio page
- `MarjanCereza.html` - Original portfolio page
